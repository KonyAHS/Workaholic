Workaholic for Windows x64
=========================

Extract this ZIP into a permanent folder, then open Workaholic.exe.
Workaholic itself does not need Python installed.
Python scripts you launch through it still need their own Python interpreter.

Settings are saved in %APPDATA%\Workaholic\services_config.json.
An older services_config.json beside the EXE is copied there on first launch
if no settings exist yet. The original file is left untouched.

To update: close Workaholic (this stops services it started), then replace
Workaholic.exe. Settings stay in AppData. Keep the EXE at the same path
if you enable launch at sign-in.

This executable is unsigned. Windows may display a SmartScreen warning.
Only run downloads you trust from https://github.com/KonyAHS/Workaholic/releases.
